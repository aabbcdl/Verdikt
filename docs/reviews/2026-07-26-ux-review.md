## Executive Summary

整体体验质量高于同类工程工具的平均水平:信息架构简单清晰(新任务/当前任务/历史记录三段)、文案以用户语言回答"是什么/接下来做什么"、错误恢复保留输入并给出可执行建议、aria-live/角色标注等无障碍骨架完整。设计意图(DESIGN.md"冷静的本地控制室")在渲染结果中成立。

最大的已验证风险是**状态真实性系统性失守**:等待确认的任务同屏显示"执行 agent 运行中"+50% 假进度条;审查完成的任务被标成红字"任务未通过"并在四处露出裸英文 `review_completed`;而"查看修改"里的补丁 diff——本产品的核心交付物——因遗留深色主题残留 CSS 呈**深字黑底、完全不可读**。此外,处于"等待确认"这一信任关键态的任务,在用户切走视图后会从所有界面入口消失,只能靠刷新页面找回。

前三优先级:U-01 统一运行状态词汇与阶段快照;U-03 修复补丁 diff 可读性并清理死掉的深色主题层;U-02 为"需要你处理"的任务建立常驻入口。视觉证据限制:未采集真实"运行中/流式输出"态与精确动作审批态(为控费未启动真实 agent),键盘焦点可见性证据存在矛盾,均列入待核验清单。

## UX/UI Execution Plan(要点)

各任务的完整字段(用户问题链、目标体验、改动清单、无障碍/响应式要求、验收与回归)以审查会话最终输出为准,此处保留可执行要点:

- **U-01 统一状态词汇与阶段快照**(CONTENT+STATE,S):`buildRunPhaseSnapshot` 补任务级 `waiting_approval` 与 review 两分支;两页 `statusLabel` 补 `review_completed/review_incomplete`;结果卡与报告页一律经词汇表;无真实进度的状态改不定态进度条(`prefers-reduced-motion` 停用动画)。验收:重拍 02/11/14 三场景矛盾消失。
- **U-02 待处理任务常驻入口**(USABILITY,S):nav"当前任务"带待确认徽标(文字进入可访问名);空态显示"有 N 个任务等待你的确认"+直达;历史列表增加置顶"进行中"分组;`startRun` 失败不清空既有 `currentRunId`。验收:重演 02→05→08 序列任一时刻两步可达。
- **U-03 补丁 diff 可读 + 死主题层退役**(VISUAL+A11Y,S+M):`.patch-review{color:#c9d1d9}` 先行(对齐 `.log-output`),可选 +/- 行着色;随后删除 8-22 行深色 `:root` 及失效规则,`ui-pages.test.ts` 锚定"仅一套 :root"。验收:diff 对比度 ≥4.5:1,关键屏截图对比无回归。
- **U-04 审查任务报告页**(STATE,S):`index.html` 增加 `reviewOnly` 分支移植 severity 卡;隐藏补丁/完整性区块;`workspaceLabel` 修正 `direct` 键;工作台侧 review 任务隐藏补丁小节与"控制下一轮"。验收:重拍 14 出现发现卡、无红色未知。
- **U-05 吸顶导航遮挡**(RESPONSIVE,XS):`html{scroll-padding-top:72px}`(或对滚动目标设 scroll-margin-top,值以 CSS 变量随断点),复核三处 `scrollIntoView`。验收:四处遮挡场景消除,原拦截滚动位点击命中行内按钮。
- **U-06 编辑再跑反馈**(USABILITY,XS):`editRunTask` 末尾 `switchView('new')`+可见确认(role=status)+焦点到目标框;文案去"左侧"。
- **U-07 历史行按钮可访问名**(A11Y,XS):模板注入 `aria-label="${动作} ${taskId}"`(对齐步骤行既有范式)。
- **U-08 统计卡布局**(VISUAL,XS):`.result-card .label/.value{display:block}` 对齐报告页 `.stat-*`,并入 U-03 清理批次。
- **U-09 时间线人话化**(CONTENT,S):`eventDetail` 为 verifier/judges/patch_ready/run_completed/note_* 五类补中文映射;三处"?"字面量改"·"并纳入守卫。

全部任务:直接发布即可(无需灰度);均无度量前置(结构性修复)。

## Systemic Design Improvements

- **状态词汇单一来源**(U-01/04/09 共享):`statusLabel`/severity/risk 词汇收敛为一份注入两页的映射——本轮四处裸英文的防复发机制。
- **遗留深色主题层退役**(U-03/08 根因):两套 `:root` 叠写是两个视觉缺陷的共同来源。
- **滚动锚点补偿制度**(U-05):导航高度 CSS 变量化,所有 sticky/scrollIntoView 引用同一变量。
